# 提示词库

## 规则

- 每个任务挑 0 到 3 条，并用一句话说明挑了哪些、为什么。几十行以内、原因清楚的小改动一条都不挑，直接做。
- 体检类四条（`c07`、`c08`、`c09`、`c10`）只在用户点名时跑。
- `d01`、`d02` 结尾的“直接合并上线”不照字面执行，改为：宣布完成前和开合并请求前过一轮审查；审查通过后问用户是否开合并请求、从哪个分支合到哪个分支；不自动开、不自动合并。
- 只读被挑中的那几条的文件（`prompts/<文件名>`）；没挑中的不读。

## 默认模型怎么定

- Gemini：文档、文案、润色、翻译、点子。
- GPT：审代码、难 Bug、后端、算法、数据处理、性能、运维排查、跨多来源的大调研。
- Claude：界面、视觉、动效、读懂代码库、架构取舍。

表里的默认按这张专长表取；任务偏向别的专长时，按上表换模型。
